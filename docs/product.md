# 제품 기획

[문서 목록](../README.md)

## 목적

복잡한 탐색 없이 짧은 철학적 문장을 읽고 생각을 환기할 수 있는 웹사이트를 만든다.
사용자의 핵심 행동은 명언을 읽고, 원할 때 스와이프로 다음 명언을 요청하는 것이다.
철학적 명언은 삶·가치·태도에 대한 성찰을 돕는 문장을 지향하며,
실제 제공 가능한 범위와 인용 신뢰도는 [데이터 조사](quote-data.md)에서 확인한다.

## 초기 MVP

| 포함 | 제외 |
|---|---|
| 첫 화면의 `생각해보기` 문구와 명언 공개 스와이프 하나 | 회원가입·로그인 |
| 스와이프 완료 후 영어 명언·저자와 한국어 AI 번역 표시 | 첫 화면에서 자동 명언 조회 |
| 스와이프로 다음 명언 요청 | 공유·카테고리·검색 |
| 로딩·실패 안내와 재시도 | DB·관리자 화면 |
| 한국어 UI, 모바일·데스크톱 대응 | AI 명언 생성 |
| 공급자 이용 조건에 따른 출처 표기 | 광고·분석 도구 |

첫 방문에는 데이터를 요청하지 않는다. 사용자가 스와이프를 완료한 뒤에만 명언을 요청한다.
영어 명언과 저자를 먼저 제공하고, Azure OpenAI의 한국어 AI 번역을 아래에 표시한다.
제공되는 영어도 고대 원어의 번역일 수 있으므로 `원어 원문`이 아니라 `영어 명언`으로 표시한다.
화면 방향은 참고작의 둥근 글래스 표면과 겹쳐진 반투명 레이어를 활용한다.
보라·남색 배경의 유리 카드 안에 가로 스와이프 조작부를 두고, 완료하면 명언을 공개한다.
모바일에서는 스와이프 조작부·긴 문장·다음 명언 동작이 잘리지 않도록 반응형으로 조정한다.

## 사용자 흐름과 상태

기본 동작은 첫 진입에 `생각해보기`, 서비스 설명과 명언 공개 스와이프 하나만 보여 주고,
사용자가 오른쪽으로 충분히 민 뒤에 명언을 공개하는 것이다. 첫 진입 때 자동 요청하지 않는다.
스와이프를 끝까지 완료하지 않으면 시작 위치로 돌아간다. 이후에도 사용자가 조작할 때만 다른 명언을 요청한다.

| 상태 | 화면과 동작 |
|---|---|
| 첫 진입 | 글래스 카드 안에 `생각해보기` 문구와 스와이프 조작부 하나를 표시한다 |
| 최초 로딩 | 스와이프 조작부 안에서 로딩 상태를 표시하고 중복 요청을 막는다 |
| 표시 완료 | 영어 명언·저자, 한국어 AI 번역과 `다른 명언 보기` 버튼을 제공한다 |
| 다음 명언 로딩 | 기존 명언을 유지하고 로딩 안내를 표시하며 중복 요청을 막는다 |
| 번역 중 | 영어 명언을 먼저 표시하고 한국어 번역 위치에 진행 상태를 표시한다 |
| 번역 실패 | 영어 명언은 유지하고 안전한 오류 안내와 번역 재시도 동작을 제공한다 |
| 최초 요청 실패 | 오류 안내와 스와이프 조작부를 통한 재시도를 제공한다 |
| 다음 요청 실패·빈 응답 | 기존 명언을 유지하고 오류 안내와 재시도 동작을 제공한다 |
| 재시도 | 같은 조작부로 한 번 요청하며 다시 로딩 상태로 전환한다 |

한국어 번역은 자동 생성 결과임을 밝히며, 정식 번역본이나 원전 해설로 표현하지 않는다.
명언이 바뀌면 이전 번역을 즉시 비우고 새 명언의 번역만 표시한다.

오류 메시지는 한국어로 제공하고 내부 응답·인증 정보는 노출하지 않는다.
응답 형식이 유효하지 않은 경우도 실패로 취급한다.
요청 시간 제한, 요청 한도 초과 안내, 연속 동일 명언 처리의 구체 정책은
공급자의 제약을 확인한 후 확정하며 무한 재요청으로 해결하지 않는다.

## 접근성과 화면 요구

- 스와이프 조작부는 키보드 방향키로 조작할 수 있고, Enter/Space로도 실행할 수 있게 한다.
- 조작부를 스크린 리더에 슬라이더로 알리고 진행률과 사용 안내를 제공한다.
- 포커스 표시, 읽기 쉬운 글자 크기·대비, 긴 문장 줄바꿈을 제공한다.
- 로딩·오류·명언 변경을 보조 기술이 인지할 수 있도록 상태 전달을 설계한다.
- 로딩 중 비활성화 상태만으로 끝내지 않고 조작부 안에 텍스트 안내도 제공한다.
- 좁은 화면에서도 본문·저자·버튼이 잘리지 않도록 한다.
- 동작 줄이기를 설정한 기기에서는 장식과 등장 애니메이션을 최소화한다.
- 외부 명언은 텍스트로 렌더링하고 HTML로 직접 삽입하지 않는다.

## 기능 검증 기준

앱 구현 시 초기 화면에 명언이 미리 표시되거나 요청되지 않는 것, 스와이프 완료 후 표시,
미완료 스와이프의 원위치 복귀, 키보드 실행, 영어 명언과 한국어 번역의 연결,
번역 중 영어 명언 유지, 번역 실패·재시도, 중복 요청 방지, 최초 실패,
기존 명언이 있는 상태의 실패·재시도, 빈 응답을 검증한다.
성공한 응답의 명언과 저자가 함께 갱신되고 실패 시 기존 명언이 유실되지 않아야 한다.
키보드 조작과 모바일 화면도 실제 브라우저에서 확인한다.
공급자·번역 API의 실시간 가용성에 의존하지 않도록 서버 통합 테스트는 응답을 모의한다.
