# 제품 기획

[문서 목록](../README.md)

## 목적

복잡한 탐색 없이 짧은 철학적 문장을 읽고 생각을 환기할 수 있는 웹사이트를 만든다.
사용자의 핵심 행동은 명언을 읽고, 원할 때 버튼 하나로 다음 명언을 요청하는 것이다.
철학적 명언은 삶·가치·태도에 대한 성찰을 돕는 문장을 지향하며,
실제 제공 가능한 범위와 인용 신뢰도는 [데이터 조사](quote-data.md)에서 확인한다.

## 초기 MVP

| 포함 | 제외 |
|---|---|
| 위에 영어 명언, 아래에 한국어 해석과 저자 표시 | 회원가입·로그인 |
| 첫 방문 시 명언 요청 | 즐겨찾기·이력 저장 |
| 버튼으로 다음 명언 요청 | 공유·카테고리·검색 |
| 로딩·빈 응답·실패 안내와 재시도 | DB·관리자 화면 |
| 한국어 UI, 모바일·데스크톱 대응 | AI 명언 생성 |
| 공급자 이용 조건에 따른 출처 표기 | 광고·분석 도구 |

영어 명언 아래에 해당 문장의 한국어 해석을 제공한다.
Stoic Quotes를 개발용 공급자로 선택했다. 한국어 해석은 Azure 번역·LLM 서비스로 제공할 방향이며,
[LLM 비교 대안으로 진행](azure-translation.md)한다. 구체 경로·모델·플랜은 초기 배포 후 확정한다.
제공되는 영어도 고대 원어의 번역일 수 있으므로 `원어 원문`이 아니라 `영어 명언`으로 표시한다.
자동 번역을 채택하면 `자동 번역`임을 표시하고 공인 번역인 것처럼 표현하지 않는다.
번역 공급자 선택 전에는 번역 기능이 구현되었다고 간주하지 않는다.
색상, 글꼴, 애니메이션 등 시각 디자인은 Web/UI 단계에서 결정한다.

## 사용자 흐름과 상태

기본 동작은 첫 진입에 요청하고, 이후에는 사용자가 버튼을 누를 때만 요청하는 것이다.
자동 새로고침이나 백그라운드 반복 호출은 하지 않는다.

| 상태 | 화면과 동작 |
|---|---|
| 최초 로딩 | 로딩 안내를 표시하고 요청 버튼을 비활성화한다 |
| 표시 완료 | 명언·저자와 `다른 명언 보기` 버튼을 제공한다 |
| 다음 명언 로딩 | 기존 명언을 유지하고 로딩 안내를 표시하며 중복 요청을 막는다 |
| 최초 요청 실패·빈 응답 | 오류 안내와 `다시 시도` 버튼을 제공한다 |
| 다음 요청 실패·빈 응답 | 기존 명언을 유지하고 오류 안내와 재시도 동작을 제공한다 |
| 재시도 | 같은 버튼으로 한 번 요청하며 다시 로딩 상태로 전환한다 |

한국어 해석은 반드시 현재 영어 문장과 연결해서 표시한다.
문장이 바뀌면 이전 해석을 그대로 표시하지 않으며 늦게 도착한 이전 번역도 버린다.
번역 중 상태를 별도로 표시하고, 번역 실패 시 영어를 유지하되 한국어 해석을 불러오지 못했음을 안내한다.
번역 재시도는 같은 영어 문장에 대해 수행한다.

오류 메시지는 한국어로 제공하고 내부 응답·인증 정보는 노출하지 않는다.
응답 형식이 유효하지 않은 경우도 실패로 취급한다.
요청 시간 제한, 요청 한도 초과 안내, 연속 동일 명언 처리의 구체 정책은
공급자의 제약을 확인한 후 확정하며 무한 재요청으로 해결하지 않는다.

## 접근성과 화면 요구

- 실제 버튼 요소를 사용하고 키보드로 조작할 수 있게 한다.
- 포커스 표시, 읽기 쉬운 글자 크기·대비, 긴 문장 줄바꿈을 제공한다.
- 로딩·오류·명언 변경을 보조 기술이 인지할 수 있도록 상태 전달을 설계한다.
- 로딩 중 비활성화된 버튼만으로 상태를 표현하지 않고 텍스트 안내도 제공한다.
- 좁은 화면에서도 본문·저자·버튼이 잘리지 않도록 한다.
- 외부 명언은 텍스트로 렌더링하고 HTML로 직접 삽입하지 않는다.

## 향후 기능 검증 기준

앱 구현 시 첫 방문 성공, 버튼 성공, 중복 요청 방지, 최초 실패,
기존 명언이 있는 상태의 실패·재시도, 빈 응답을 검증한다.
성공한 응답의 명언과 저자가 함께 갱신되고 실패 시 기존 명언이 유실되지 않아야 한다.
영어·한국어 문장의 일치, 번역 실패, 다음 명언 요청 후 이전 번역의 지연 응답도 검증한다.
키보드 조작과 모바일 화면도 실제 브라우저에서 확인한다.
데이터 공급 방식에 의존하는 조건은 API 선정 후 이 문서에 반영한다.
