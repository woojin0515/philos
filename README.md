# Philos

버튼 하나로 철학적인 명언을 만나고 잠깐의 동기부여를 얻는 웹사이트.
`Philos`는 작업명이며 공개 서비스명은 아직 정하지 않았습니다.

## 현재 단계

**기획·개발 문서와 초기 폴더 구조만 준비한 상태입니다.**
앱 코드, 패키지 설정, 개발 서버, 배포된 사이트는 아직 없습니다.
현재 실행할 수 있는 설치·개발·빌드 명령은 없습니다.

## 만들고자 하는 경험

첫 방문에 명언과 저자를 보여 주고, 버튼을 누르면 다른 명언을 요청합니다.
UI는 한국어를 사용하며 명언 자체의 제공 언어는 데이터 공급 방식 결정 후 확정합니다.
로그인, 즐겨찾기, 공유, DB, 자동 번역은 초기 MVP에 포함하지 않습니다.

## 추천 기술스택

| 구분 | 추천안 |
|---|---|
| 프런트엔드 | React + TypeScript + Vite |
| 스타일 | 기본 CSS |
| 데이터 요청 | 브라우저 `fetch`, 외부 API 우선 검토 |
| 패키지 관리 | npm |
| 품질 도구 | ESLint, TypeScript, Vitest + React Testing Library |
| 배포 | Azure Static Web Apps 우선 검토 |

위 구성은 개발 세팅 단계에서 적용할 추천안입니다.
API 제공자는 아직 조사·선정하지 않았고 서버·DB 도입도 확정하지 않았습니다.

## 다음 단계

1. 문서 작성 이후 명언 API를 조사하고 데이터 공급 방식·언어를 결정합니다.
2. 조사 결과를 문서에 반영하고 개발 환경과 최소 실행 프로젝트를 구성합니다.
3. 최소 앱을 Azure Portal을 통해 초기 배포하고 실제 URL에서 확인합니다.
4. 별도 Web/UI 브랜치에서 핵심 기능을 구현합니다.

이번 문서·폴더 세팅에는 API 조사, 의존성 설치, 앱 구현, Azure 리소스 생성이 포함되지 않습니다.
